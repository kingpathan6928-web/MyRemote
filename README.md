# MyRemote Frontend — Milestone 1

Mobile-friendly Vite + React frontend starter for MyRemote.

## Included
- Dark / light theme toggle
- Overview dashboard
- Separate APK Builder and Wallpaper Studio tabs
- Fast Build and Advanced Build UI
- URL, app name, package name and custom icon input
- Six selectable permission-module UI options
- Build History placeholder

## Run locally
1. Install Node.js 20+
2. Run `npm install`
3. Run `npm run dev`

## Important status
This is frontend milestone only. It does **not** generate APKs, authenticate users, save projects, or control a phone yet. Those require Supabase, a backend, Android template/build pipeline, and a companion Android app for wallpaper actions.

Only package websites you own or are authorized to package. Permission options are configuration requests, not automatic Android grants. Native implementation and runtime consent are required.
